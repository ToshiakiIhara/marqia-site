1to1Match プライバシーポリシー

MARQIA（以下「当事業者」）は、1to1マッチングのサービス「1to1Match」（以下「本サービス」）での、利用者の情報の扱いを、次のとおり定めます。

第1版
制定日：2026年11月19日

1. 取得する情報

本サービスは、次の情報を取得します。

(1) Googleアカウントの情報

Googleでログインしたときに、Googleから次の情報を受け取ります。

  • 名前、メールアドレス、プロフィール写真のURL

(2) Googleカレンダーの情報

本サービスは、Googleカレンダーについて、次の2つの権限だけを求めます。

  • 空き時間を読む権限（calendar.freebusy）：予定が入っている時間帯だけを読みます。予定のタイトル・場所・説明・参加者などの中身は読みません。読んだ「予定が入っている時間帯」は、1to1の候補の時間を計算するときにだけ使い、保存しません
  • 本サービスが作ったカレンダーにだけ予定を作る権限（calendar.app.created）：本サービスが作ったカレンダーの中の予定だけを、作ったり変えたり消したりできます。利用者のほかのカレンダーの予定は、読むことも書くこともできません

1to1の予定は、本サービスの事務局のアカウント（1to1match@marqia.jp）のカレンダーに作り、1to1をする2人を招待します。招待には、2人の名前・メールアドレス、日時、Google Meet のリンク、本サービスが提案した理由の1行が入ります。

(3) 利用者が登録する情報

  • 業種、理想の顧客、繋がりたい業種、紹介できる人脈（「業種×役職」などの区分で選ぶもので、人の名前は登録しません）、1to1の候補にしてよい時間帯、アピールの一言、週の回数（休止を含む）、顔写真の扱い、項目ごとの「見せる範囲」、特に会いたい人

(4) 本サービスの利用の記録

  • 提案した1to1、招待への返事（参加する・しない）、1to1をしたかどうか、1to1のあとの紹介の記録（紹介した・これから紹介する・今回はなし・会えなかった）、使った機能と日時

(5) 連携のための情報

  • Googleの連携を続けるための情報（リフレッシュトークン）。暗号化して保存し、本サービスのサーバーの中だけで使います

(6) ログインの状態を保つための情報

  • ログインの状態を保つために、Cookie を使います

(7) 料金の支払いに関する情報（有料になってから）

  • 支払いは、Stripe（Stripe, Inc.）を通して行います。カード番号は、当事業者は受け取らず、保存もしません。当事業者が持つのは、Stripe の顧客の番号、契約の状態（無料期間中・有料・未払い・解約）、プランです

2. 使う目的

取得した情報は、次の目的にだけ使います。

  1. 利用者どうしの1to1の相手と日時を提案すること（マッチング）
  2. 1to1の予定を作り、Google Meet のリンクを付けて招待すること
  3. 1to1の前後の案内（提案の理由、前日の案内、翌朝の振り返り、紹介のヒントなど）を送ること
  4. 本サービスの改善と、利用の状況の集計（個人が分からない形の集計を含む）
  5. 料金の請求と、契約の管理
  6. 問い合わせへの対応、不正な利用の防止

3. ほかの利用者に見えるもの

  • 1to1が決まった相手には、利用者の名前、メールアドレス（Googleカレンダーの招待に表示されます）、提案の理由の1行が見えます
  • 業種、アピールの一言、理想の顧客などは、利用者が決めた「見せる範囲」（同じチャプターまで／他のチャプターにも／見せない。最初は「同じチャプターまで」）に従って、ほかの利用者に見えることがあります
  • 「特に会いたい人」に選んだことは、選ばれた相手には知らせません
  • 提案の点数や候補の一覧は、利用者には見せません

4. 運営が見るもの

当事業者（本サービスの運営）は、本サービスの運営・改善のために、次の情報を見ることがあります。

  • 登録された情報、提案の候補と点数の内訳、特に会いたい人、利用の記録

5. Googleから受け取った情報の扱い

本サービスが Google API から受け取った情報の使い方と、ほかへの渡し方は、Google API サービスのユーザーデータに関するポリシー（Google API Services User Data Policy）の「Limited Use（使い方の制限）」の要件を含めて、そのポリシーに従います。

  • Googleから受け取った情報は、上の「2. 使う目的」のためにだけ使います
  • 広告のために使ったり、売ったりしません
  • 人が読むのは、利用者の同意がある場合、セキュリティのために必要な場合、法律で求められる場合だけです

外国にある事業者に情報を預けることについて

  • Google は、データを世界の複数の国のデータセンターに分けて保存していて、どの国のサーバーに置かれるかを、利用者ごとに公表していません。そのため、Google に預ける情報を置く国は、特定できません

  • 当事業者は、「8. 安全のための取り組み」の措置をとっています
  • 本サービスに登録するときに、外国の事業者に情報を預けることを含めて、このポリシーへの同意をいただきます

7. 第三者への提供

次の場合を除いて、利用者の同意なく、個人情報を第三者に渡しません。

  • 法律に基づく場合
  • 人の命・体・財産を守るために必要で、本人の同意を得るのが難しい場合
  • そのほか、個人情報の保護に関する法律で認められている場合

8. 安全のための取り組み

  • Googleの連携の情報（リフレッシュトークン）は、暗号化して保存します
  • データベースでは、利用者が自分の情報と、自分が関わる1to1の情報だけを見られるように、行ごとに見られる範囲を絞っています
  • 秘密の鍵は、本サービスのサーバーの中だけで扱います

9. 保存する期間と、削除

  • 利用者が退会したとき、または削除を求めたときは、利用者の情報を削除します。ただし、法律で保存が求められる記録（料金の記録など）は、その期間だけ保存します
  • Googleの連携は、利用者がいつでも解除できます（Googleアカウントの「サードパーティ製のアプリとサービス」から）。解除すると、本サービスはカレンダーを読めなくなります

10. 開示・訂正・利用の停止などのお願い

利用者は、自分の情報の開示、訂正、追加、削除、利用の停止などを求めることができます。下の窓口にご連絡ください。本人であることを確かめたうえで、法律に従って対応します。
